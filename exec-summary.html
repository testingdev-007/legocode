What it is

Teams run their own three-stage delivery pipeline — Designer → Dev → Tester — building Lego minifigures to a spec instead of shipping software. A Designer turns a short brief into structured requirements, a Dev writes build instructions and builds them, and a Tester checks the result and can send it back for a fix. Partway through, a live "production incident" changes the spec mid-build — a concrete, physical demonstration that passing review doesn't guarantee nothing goes wrong at runtime.

Why it works

  • No prior coding knowledge needed — every construct (variables, conditionals, exceptions, assertions) is taught through a physical action, not a screen.
  • Every stage maps to a real job, explicitly, including financial-services-specific roles (Business Analyst, Risk & Controls, Trading Systems Support) — giving attendees a concrete "this could be me" moment.
  • Continuous flow, not scripted rounds — the pipeline runs as a real Kanban system, so nobody sits idle waiting for a turn.
  • Competitive without being exclusionary — teams score on throughput, quality, and defects caught, not just speed, rewarding careful work as much as fast work.
  • An optional escalation with real teeth — a toggleable "virus" crisis can wipe a team's entire physical build, mid-work or already finished, while their score stays untouched — a live, physical lesson in why disaster recovery and immutable audit logs are a regulatory requirement in finance, not a nice-to-have.

What attendees take away

A working mental model of an actual software delivery pipeline — requirements, build, review, release, and the fact that testing exists because things go wrong even when code is written correctly. Delivered physically and competitively, with a live scoring reveal, rather than lectured.

"You just ran: turn a requirement into data → write and run code → test it — the same loop that repeats every sprint in a real delivery team."

Supporting tools

Four companion tools run the day: a per-team pipeline console, a whole-room presentation mode for when laptops are scarce, a host leaderboard, and a facilitator hub covering setup, scoring, and troubleshooting. All are self-contained, offline-safe web pages — no installation, no account, no cost beyond the Lego itself.
